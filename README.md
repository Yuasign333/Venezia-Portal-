# Venezia-Portal-Venezia-Subdivision-Amenity-Reservation-Payment-and-Community-Management-System
Venezia Portal is a web-based system for Venezia Subdivision in Las Piñas. It replaces the current paper log and informal messaging with a database-backed platform for amenity scheduling (basketball court, swimming pool, table tennis, events area), HOA dues recording, announcements, concern reports, and a security visitor log.
